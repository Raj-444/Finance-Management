# Personal Finance Manager

A fast, lightweight, distraction-free Personal Finance Manager built specifically for plain PHP 8.2 + MySQL/MariaDB and shared cPanel hosting.

---

## ⚡ Highlights
- **cPanel-first**: Zero Node.js or long-running daemon processes required on the server.
- **Fast 2-tap tracking**: Category chip selection, large keypad, under 5-second entry time.
- **Smart Budgets & Forecast**: Real-time spending run-rate projection and proactive warning alerts.
- **Dual Language**: Seamless English (`en`) and Bangla (`bn`) interface with native Bangla digits option (`০-৯`).
- **Data Portability**: High-performance streaming Excel (`.xlsx`) and `.csv` import/export powered by OpenSpout, plus one-click JSON backups.
- **Secure Financial Math**: All currency stored as `BIGINT` minor units (paisa) to prevent float rounding errors (default `BDT ৳`).
- **Security Hardened**: Argon2id password hashing, 15-minute 5-failure login rate limiting, expiring single-use reset tokens, and strict `user_id` query scoping.

## 📂 Architecture & Folder Layout
```text
/home/CPANELUSER/finance_app/          (Protected, one level above web root)
  app/
    Core/        (Autoloader, Router, Request, Response, Database, Session, Csrf, I18n, Logger)
    Controllers/ (InstallController, AuthController, DashboardController, SettingsController)
    Models/      (User, LoginAttempt, PasswordReset, AppSetting)
    Services/    (Mailer, BudgetForecast, ExcelService)
    Views/       (Server-rendered PHP templates with layout components)
    Lang/        (en.php, bn.php)
    Helpers/     (helpers.php - global security, money, and escaping helpers)
  bin/cron.php   (cPanel scheduled cron job runner)
  config/        (config.php generated by installer)
  database/      (schema.sql, migrations runner)
  storage/       (logs, sessions, cache, backups, tmp)
  vendor/        (Committed dependencies: PHPMailer, OpenSpout)
  bootstrap.php

/home/CPANELUSER/public_html/          (Document root)
  index.php      (Requires ../finance_app/bootstrap.php)
  .htaccess      (Clean URL rewrites, gzip compression, security headers)
  manifest.webmanifest (PWA support)
  sw.js          (Offline shell service worker)
  assets/        (tokens.css, app.css, app.js, alpine.min.js, chart.min.js)
```

## 🚀 Local Development & Testing

### 1. Requirements
- PHP >= 8.2 with `pdo_mysql`, `pdo_sqlite`, `mbstring`, `zip`, `xml`, `openssl`, `json`, `fileinfo`.

### 2. Run Built-In Development Server
```bash
php -S localhost:8000 -t public_html
```
Open [http://localhost:8000](http://localhost:8000) in your browser. If not installed, you will be automatically redirected to `/install`.

### 3. Run Automated Tests
```bash
php tests/Phase1Test.php
php tests/InstallerTest.php
```

## 📅 Scheduled Cron Job (cPanel)
Add this entry to your cPanel **Cron Jobs** to run every 15 minutes:
```text
*/15 * * * * /usr/local/bin/php /home/CPANELUSER/finance_app/bin/cron.php >/dev/null 2>&1
```
